# 分部估值方法论约束与红线

> 本文件是 `stock-expectation-gap-analysis` skill 的配套参考，用于约束分部估值（SOTP）和可比估值中的方法论陷阱。在 `references/framework.md` Step 4 及情景分析中执行估值时，必须对照本文件检查。

---

## 1. 分部估值的前提条件

分部估值（Sum-of-the-Parts）不是万能工具，必须满足以下前提才能使用：

| 条件 | 要求 | 不满足时的替代方案 |
|------|------|------------------|
| 分部营收 | 年报/公告中有明确的业务板块收入拆分 | 无法做分部估值，只能做整体估值 |
| 分部毛利率 | 至少有各板块的毛利率或毛利额数据 | 只能做 PS 估值，禁止做 PE 估值 |
| 分部利润 | 经审计的分部利润表，或经交叉验证的调研数据 | 禁止拍"分部利润"，只能估算毛利额 |
| 独立性 | 各业务板块有独立可比的上市公司 | 若某业务无纯可比公司，说明市场缺乏定价锚，估值误差会放大 |

**核心原则**：没有分部利润表时，禁止拍"分部利润"做 PE 估值。只能做"营收分部 × 行业 PS"的粗略估算，并在报告中明确标注"基于营收的粗略估算，精度有限"。

---

## 1.5 大宗原材料成本占比高的行业：PS 天然失真

**电缆、有色金属加工、化工等大宗原材料成本占比高的行业，PS 估值天然失真**。原材料价格上涨会抬高营收但不必然增加利润，导致 PS 在原材料高位年份被低估、低位年份被高估。

**优先估值方法**（按推荐顺序）：

1. **正常化毛利额估值**（更贴近真实价值创造能力，剥离原材料价格波动）
2. **EV/EBITDA**（剥离资本结构和折旧差异，更反映经营实质）
3. **正常化经营利润估值**（扣除期间费用后的真实盈利，但需有利润数据）

**若必须使用 PS**，必须在报告中注明："原材料成本占比高，营收受价格波动影响，PS 仅供参考，精度有限。"

案例：电缆行业原材料成本占比 93-94%，铜价上涨 42% 会把营收推高，但毛利率反而下降。此时用 PS 估值会高估企业价值，应优先使用正常化毛利额或 EV/EBITDA。

## 2. 亏损年份口径规则

### 绝对禁止

- **公司整体亏损时，禁止报告"某业务利润占比"**。数学上可能成立（分母为负），经济学上失真。
- 亏损年份的"利润占比"会被误读为"该业务不重要"或"该业务被忽视"，实际上可能是"该业务也在亏损，只是亏损幅度较小"。

### 替代口径

| 指标 | 为什么可用 | 注意事项 |
|------|-----------|---------|
| 营收占比 | 不受整体盈亏影响 | 高营收不等于高价值（如毛利率极低） |
| 毛利率 | 反映业务本身的成本覆盖能力 | 需对比行业平均，判断是否有竞争力；**毛利为正不等于分部盈利** |
| 毛利额 | 反映该业务对公司总毛利的贡献 | 可用于比较各业务板块的价值创造 |
| 经营性现金流 | 反映业务真实的现金创造能力 | 比利润更抗会计调节 |
| 产能利用率 | 反映产能爬坡阶段和真实经营状态 | 新业务的产能利用率比利润更有信息量 |

### 禁止用毛利率推断分部盈利状态

**毛利率反映的是产品本身的成本覆盖能力，分部净利润还需扣除销售费用、管理费用、研发费用、财务费用、折旧摊销等期间费用。** 因此：

- **禁止**表述："该业务盈利"、"该业务亏损"、"接近盈亏边缘"（除非有分部利润表数据）
- **正确**表述：
  - "毛利为正，但分部净利润未知（期间费用未分摊）"
  - "毛利率极低，扣除期间费用后大概率盈利能力较弱或亏损"
  - "分部利润未披露，无法判断该业务是否单独盈利"

## 3. 利润归因规则

### 禁止单因素归因

**推断"某业务/某因素是核心驱动力"时，必须列出其他可能因素并评估权重。**

案例：2026Q1 利润同比大增 280%，可能来自：
1. 光通信产品价格上涨（A级）
2. 铜价成本传导改善（A级）
3. 费用率下降（A级）
4. 减值低基数（2025Q1 无大额减值，A级）
5. 订单结构变化（高毛利订单占比提升，B级）
6. 存货收益（铜价上涨带来的库存增值，C级）
7. 所得税变化（递延所得税资产释放，A级）

**未拆分明细前，禁止写"核心驱动力是光通信"**。正确表述："光通信量价齐升是已知的重要正向因素之一，但 2025Q1 的低基数、成本传导改善和费用率变化同样贡献了显著增量，各因素权重需待半年报分部数据进一步确认。"

## 4. 可比公司分组规则

### 禁止混池

可比公司必须按**主营业务属性**分组，禁止把不同业务属性的公司混在一起算"行业平均"。

| 分组 | 典型公司特征 | 杭电股份案例 |
|------|-------------|-------------|
| **传统电缆组** | 以电力电缆/导线为主，毛利率 10-15% | 起帆电缆、万马股份、汉缆股份 |
| **光通信组** | 以光纤光缆为主，有光棒/光芯片能力 | 长飞光纤、亨通光电（部分）、中天科技（部分） |
| **海缆组** | 以海底电缆/海上风电为主，毛利率 20-30% | 东方电缆、中天科技（部分） |
| **PCB/电子材料组** | 以覆铜板、电子铜箔为主 | 生益科技、华正新材、南亚新材 |
| **锂电材料组** | 以锂电铜箔、正极材料为主 | 诺德股份、嘉元科技、中一科技 |

**错误做法**：把东方电缆（海缆龙头，毛利率 22%）和起帆电缆（传统电缆，毛利率 12%）混在一起算"行业平均 PE"，然后用这个平均 PE 给杭电股份的电缆业务估值。

**正确做法**：电缆业务对标传统电缆组（起帆、万马、汉缆），光通信业务对标光通信组（长飞光纤），铜箔业务对标 PCB/电子材料组或锂电材料组（视实际产品而定）。

## 5. 结论表达方式

### 禁止精确点估计

| 错误表述 | 正确表述 |
|---------|---------|
| "合理估值 70-100 亿，下行 75-80%" | "当前估值明显超出分部估值上限（电缆约 60-100 亿），安全边际严重不足" |
| "电缆业务值 70 亿" | "电缆业务按传统电缆组 2-3 倍 PB，对应约 50-80 亿区间" |
| "铜箔业务估值为 0" | "铜箔业务短期盈利不确定，若按 PS 0.5-1 倍估算约 5-10 亿，但需扣除产能爬坡风险" |

**核心原则**：分部估值只能输出**区间**，不能输出**精确点**。区间上下限之间本身就反映了不确定性，强行压缩成一个精确数字会制造虚假的确定性。

## 6. 减持/增持信息处理

### 仅作情绪面/筹码面信号

大股东减持/增持只能作为**风险偏好和筹码供给的观察信号**，不能作为**基本面证据**。

| 信号类型 | 可解读的范围 | 禁止的解读 |
|---------|-------------|-----------|
| 高位减持 | 增加筹码供给、压制短期风险偏好 | "股东认为公司不值这个钱"、"用脚投票" |
| 低位增持 | 显示管理层信心、提供情绪支撑 | "基本面已经见底"、"股价跌无可跌" |
| 质押解除 | 降低流动性风险 | "大股东准备继续减持"（无直接证据时） |

**必须披露的可能原因**：
- 资金需求（集团其他业务需要资金、个人资金需求）
- 股权结构安排（家族财富分配、股权激励稀释后的平衡）
- 质押压力（股价逼近质押线，被动减持）
- 历史持股套现（早期投资者退出，与当前基本面无关）

**正确表述**："二股东在高位持续减持（已减持至 50%，计划再减持 3%），增加了市场筹码供给，对短期风险偏好形成压制。减持原因可能涉及集团资金需求，不能等同于对基本面的否定，但需持续跟踪后续减持进展。"

## 7. 估值结论自检清单

在报告最终定稿前，用以下清单检查估值部分：

- [ ] 分部估值的每项利润是否有来源（年报分部数据、公告、可交叉验证的调研）？
- [ ] 亏损年份是否错误报告了"利润占比"？
- [ ] 是否将推算值当作实测值用于估值？
- [ ] 可比公司是否按业务属性分组？是否混池？
- [ ] 结论是否使用了精确点估计（如"下行 75%"）？应改为区间估计。
- [ ] 是否将减持解释为基本面证据？应改为情绪/筹码面信号。
- [ ] 产业链口径是否对齐？有无跨子赛道直接类比？
- [ ] 单因素归因是否被禁止？是否列出了其他可能因素？
- [ ] **毛利率是否被误用为"分部盈利"推断**？是否写成"毛利为正，但分部净利润未知"？
- [ ] **大宗原材料行业是否优先使用正常化毛利额/EV/EBITDA，而非PS**？
- [ ] **公司整体估值指标是否被错误标注为某业务板块**？
- [ ] **结论是否列出了当前估值依赖的尚未验证假设**，而非笼统的"严重超出基本面"？
