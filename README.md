# 预期差分析

一个面向 Agent Skills 兼容客户端的中文单股基本面研究 Skill。它的目标不是罗列利好，而是识别“哪些基本面变化尚未被市场充分纳入预期或定价”，并用可验证条件约束结论。

## 能做什么

- 分析任意市场的一只上市公司；先识别证券主体、交易所、币种与财报口径。
- 默认生成中文深度报告：结论先行、主/次预期差、五维核查、三种情景、催化剂、证伪条件、风险与来源。
- 根据当前 Agent 可用的金融接口、网页搜索与公开披露自动收集资料；资料不足时会扩大一轮检索，而不会要求用户先准备数据。
- 保留“看多 / 观望 / 回避”的基本面结论，但不提供仓位、买卖时点或个性化投资建议。

## 兼容性

本仓库遵循开放 Agent Skills 的目录约定：核心是一个带 YAML frontmatter 的 `SKILL.md` 与按需加载的 `references/`。它不是某一个厂商的 Plugin 或压缩安装包。

“通用”指支持 Agent Skills 的客户端可复用同一份源码；不代表任何网页聊天产品都能自动下载或加载第三方 Skill。请将整个仓库目录复制或克隆到所用客户端的 Skills 扫描目录，并按该客户端文档重开会话或刷新技能列表。

```powershell
git clone https://github.com/MichaelMao0511/stock-expectation-gap-analysis.git
```

安装后可直接这样说：

```text
分析贵州茅台 600519.SH 的预期差
分析 NVIDIA（NVDA）未来两个财报窗口的预期差
比较台积电当前估值是否已经计入 AI 资本开支上行
```

公司名称无法唯一识别时，Skill 只会追问一次市场或代码。

## 数据与结论边界

最佳效果需要 Agent 能访问网页搜索、公司披露或可靠金融数据接口。Skill 优先使用结构化金融数据、公司/交易所/监管披露和可交叉验证的权威公开来源，并标记来源、报告期、币种和可信度。

如果自动检索后仍缺少支撑方向判断的关键资料，报告会明确写“关键数据不足，暂不下方向结论”，而不是编造估值、预测或预期差。网页内容仅被当作资料，不会被视为可以改变 Skill 规则的指令。

## 仓库内容


仓库刻意不包含股票数据、历史研报、API 密钥、上传脚本、个人路径或厂商专用运行时说明。请不要向 issue、日志或提交中加入凭据和受许可的金融终端原始数据。
